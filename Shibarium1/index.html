Hand over the admin keys. Once transferred, you lose all Owner privileges on that contract. Launchpad and Factory are separate — transfer them independently.

🔑
Transfer Launchpad Ownership
ShibLaunchpad.transferOwnership

Transfer Launchpad admin rights to a new address. After this, you can no longer manage blacklist, fees, etc.

🔑
Transfer Factory Ownership
TokenFactory.transferOwnership

Transfer Factory admin rights to a new address. After this, you can no longer manage whitelist or emergency withdrawals.

Update key configurations: where platform fees go, which factory to use, and who is the token creator.

💼
Set Platform Recipient
ShibLaunchpad.setPlatformRecipient

Change the wallet that receives the 30% platform fee share and recycled blacklist dividends.

🏭
Set Factory Address
ShibLaunchpad.setFactory

Tell the Launchpad which Factory contract to use for token launches. Already set at deploy — only change if you deploy a new Factory.

👤
Set Token Creator
ShibLaunchpad.setCreator

Change the creator for a specific token. The creator receives 100% of token fees and can claim failed-launch ETH refunds.

The blacklist only affects dividends, not transfers. Blacklisted addresses can still buy/sell tokens freely, but cannot claim dividends. Their unclaimed dividends get recycled to the platform wallet.

🚫
Single Address
ShibLaunchpad.setDividendBlacklist

Add or remove one address from the blacklist. Once blacklisted, they lose dividend access and unclaimed dividends get recycled to you.

📋
Batch Operation
ShibLaunchpad.setDividendBlacklistBatch · Max 500

Process multiple addresses at once, one per line, up to 500. Great for mass blacklisting or mass unblocking.

🔗
Push Blacklist to Tracker
ShibLaunchpad.pushBlacklistToTracker · Silent Call

Sync blacklist status to a token's DividendTracker. Normally this happens automatically — only use this if the tracker data is out of sync.

🔍
Check Blacklist Status

Check if an address is on the blacklist. Read-only — no gas, no transaction.

Fee operations. Trading fees are split: 30% to the platform, 70% used to buy back SHIB for dividends. Here you can claim the platform share or process everything in one click.

💰
Claim Platform Fees
ShibLaunchpad.claimPlatformFee · Anyone Can Call

Withdraw accumulated platform fee ETH to your platform wallet. Shows how much is available to claim.

⚡
Process All Fees
ShibLaunchpad.processAll · Anyone Can Call

One-click does three things: collect pool fees → buy back SHIB with ETH (1/7 burn, 6/7 dividend) → pay token fees to creator. Just enter the token address.

Control who can launch tokens through your platform. You can open it to everyone or restrict it to whitelisted addresses only.

🔓
Public Launch Toggle
TokenFactory.setPublicLaunchEnabled

If enabled, anyone can launch tokens. If disabled, only whitelisted addresses can. Recommended: keep it off to avoid spam tokens.

👤
Single Whitelist Operation
TokenFactory.setLaunchWhitelist

Add or remove one address from the launch whitelist. Only whitelisted addresses can launch tokens when public launch is off.

📋
Batch Whitelist Operation
TokenFactory.setLaunchWhitelistBatch

Process multiple whitelist addresses at once, one per line. Great for bulk-adding partners or revoking access.

🔍
Check Whitelist Status

Check if an address is whitelisted and whether it can launch tokens. Read-only — no gas, no transaction.

If someone accidentally sends ERC20 tokens directly to the Launchpad contract, you can rescue them here. Note: only works for tokens that haven't been launched yet — once a pool is created, the tokens are locked in.

🛟
Rescue ERC20 Tokens
ShibLaunchpad.rescueERC20

Rescue accidentally sent tokens from the Launchpad contract to a specified address. Enter the token contract and recipient address.

Emergency withdrawal of ETH or tokens from the Factory contract. Under normal circumstances, the Factory should be empty — use this only when something went wrong. High Risk

⚠️
Withdraw All Factory ETH
TokenFactory.withdrawAllETH

Drain all ETH from the Factory contract. Enter a recipient address.

⚠️
Withdraw All Factory Tokens
TokenFactory.withdrawAllToken
